# RAVEN STORE

موقع عربي ثابت لمتجر ألعاب رقمي. لا يحتاج إلى قاعدة بيانات أو سيرفر.

## قبل النشر
1. افتح `config.js` وبدّل `YOUR_TELEGRAM_USERNAME` إلى اسم مستخدم حساب المتجر على تيليجرام بدون @.
2. بدّل المنتجات والأسعار التجريبية إلى منتجاتك الحقيقية. كل منتج يحتوي على `name` و `artTitle` و `category` و `price` و `description` و `color`.
3. احفظ التغييرات.

## النشر على GitHub Pages
1. أنشئ حساباً على https://github.com إذا لم يكن عندك حساب.
2. أنشئ مستودعاً عاماً جديداً (Public repository) باسم `raven-store` أو اسم آخر.
3. ارفع `index.html` و `config.js` في جذر المستودع (Add file > Upload files > Commit changes).
4. من Settings > Pages، اختر Deploy from a branch، ثم Branch: main، Folder: /(root)، واضغط Save.
5. انتظر حتى يظهر رابط الموقع: https://USERNAME.github.io/raven-store/ (استبدل USERNAME باسم حساب GitHub).
6. لتحديث الأسعار لاحقاً: افتح `config.js` من المستودع > Edit (رمز القلم) > Commit changes، ثم انتظر تحديث الموقع.

## ملاحظات
- الموقع ثابت، ولا يحتوي على تسجيل مستخدمين أو سلة مشتريات أو دفع مباشر أو تحديث تلقائي للأسعار.
- عند الضغط على اطلب الآن ينسخ المتصفح تفاصيل المنتج إن سمحت صلاحياته، ويفتح حساب المتجر على تيليجرام. على بعض المتصفحات قد تحتاج نسخ التفاصيل يدوياً.
- تجنب وضع مفاتيح API أو كلمات مرور في الملفات؛ ملفات GitHub Pages عامة.
- جميع الأسعار المعروضة عند الإنشاء تجريبية.
